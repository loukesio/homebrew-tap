# loukesio/homebrew-tap

Homebrew formulae by [@loukesio](https://github.com/loukesio).

```bash
brew install loukesio/tap/paperwatch
brew services start paperwatch
```

| formula | description |
|---|---|
| [paperwatch](https://github.com/loukesio/paperwatch) | Automatically rename downloaded scientific papers using DOI/arXiv metadata |
